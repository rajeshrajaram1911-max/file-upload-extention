Secure Share Options

Upload host

The encrypted envelope (ciphertext only, never the key) is uploaded here. The decryption key stays in the share link fragment, so the host cannot read your file.

Your endpoint receives a multipart/form-data field named file and should reply with JSON containing a url, link, or data.url field, or with a plain-text URL.

About security

Files are encrypted with AES-256-GCM entirely in your browser before upload. The random key is appended to the share link as #key=.... Anyone with the full link (URL + fragment) can decrypt; the host only ever sees ciphertext.

History is stored in the extension's local storage and can be cleared with the Clear share history button.
